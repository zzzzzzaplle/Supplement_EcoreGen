1. Create an IPO application. A retail customer starts an IPO application by providing the target company, the number of shares greater than 0, the payment amount greater than 0, and a non-null allowance document. The system checks that the customer is currently eligible to apply and has no approved application for the same company name. The operation returns true when the application record is created successfully; otherwise, false.
2. Approve or reject an application. The bank can approve or reject only a pending application. Approval is allowed only when the related customer is still eligible to apply for IPO. When the bank approves an application, the system sends two information emails, one to the customer and one to the company. When the bank rejects an application, the system sends one rejection email to the customer, and the rejection email content includes the customer's name, surname, email address, telephone number, the company name, the number of shares, and the paid amount. The operation returns true on success; otherwise, false.
3. Retrieve a customer's application-count summary. The customer can view how many IPO applications have been completed in total. Only approved and rejected applications are counted. Pending applications and canceled applications are not counted. The operation returns 0 when the customer has no approved or rejected applications.
4. Query the total approved IPO application amount for a customer. The customer can view the sum of the paid amounts of all approved IPO applications. Pending and rejected applications are excluded from the total. The operation returns 0 when the customer has no approved applications.
5. Cancel a pending application. By providing a company name, a customer can cancel an application that is still pending. Approved and rejected applications cannot be canceled. The operation returns true when cancellation succeeds; otherwise, false.
