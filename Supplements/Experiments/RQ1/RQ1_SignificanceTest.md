# RQ1 Overall Problem-Level Paired Sign-Flip Permutation Test

## Method Description

This report uses an overall problem-level paired sign-flip permutation test. The 14 problems from JavaBench and TLBench are merged into a unified set. For each problem, the average Pass% across all samples is computed first; then, under the same model, the problem-level difference between the reference method and each compared method is calculated.

The null hypothesis is that the two methods have no systematic difference, so the sign of each problem-level difference can be randomly flipped. For each comparison, this report performs 10,000 random sign-flip permutations and computes the two-sided p-value using `(b + 1) / (m + 1)`.
Random seed: seed=20260630.
